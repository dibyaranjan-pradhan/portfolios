iOS Versions (Semantic Versioning)

Minimum Supported Version

ℹ️ The lowest version allowed to use the app. Users below this version will be forced to update if "Force Upgrade" is enabled. If they update anyway, they won't be able to proceed without upgrading first.

Latest Version

ℹ️ The current newest version available. Users below this version will see an "Update Available" notification but can still use the app.

Update Settings

Update Message

ℹ️ This message will be shown to users when an update is available. Use this to explain why they should update (e.g., "Security fixes", "New features", etc.).

Force Upgrade

ℹ️ When enabled, users below the minimum supported version will be forced to update the app. They will see a non-dismissible modal and cannot proceed without updating. When disabled, only the "Latest Version" check applies, showing optional update notifications.

Feature Flags

When enabled, the Events tab and event-related features are visible to users in the app.

When enabled, unverified users will be prompted in the app to take a selfie and verify their identity against their profile picture using AWS Rekognition. Verified profiles are shown with a badge and get priority in requests.

When enabled, users can access referral features during registration and from Settings.

When enabled, male users see a "Last Searched Clubs" section on their Home screen showing clubs/areas they recently searched for.

When enabled, users see a "Recently Booked Clubs" section on their Home screen showing places they've previously booked.

When enabled, users see a "Top Visited Places Nearby" section listing the places with the most club visit plans created by fUsers this week, filtered to their nearby area.
