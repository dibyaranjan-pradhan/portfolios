# Grand Vere Hotels & Resorts

A standalone static hotel group website inspired by the supplied Grand Vere reference image. The homepage introduces the collection, filters individual hotels by destination type, provides a booking dialog, and includes editorial, newsletter, and responsive mobile navigation experiences.

## Run locally

From this directory, run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

The site has no build step. Photography is loaded from Unsplash's image CDN for the prototype.
